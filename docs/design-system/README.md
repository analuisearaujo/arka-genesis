# ARKA Genesis — Design System

## Visão

O ARKA Design System define a linguagem visual,
interativa e tecnológica da ARKA Genesis.

## Princípio

Ciência + tecnologia + natureza + sofisticação.

## Identidade

ARKA deve transmitir:

- inteligência
- confiança
- descoberta
- natureza
- precisão
- tecnologia
