# ARKA Dataset V1

Primeiro conjunto oficial de treinamento da ARKA Vision.

## Objetivo

Construir uma base organizada para identificação de serpentes brasileiras.

## Estrutura

- Crotalus durissus
- Bothrops jararaca
- Boa constrictor
- Micrurus

## Padrão das imagens

- fotografia nítida
- sem marca d'água
- espécie identificada
- boa iluminação
- diferentes ângulos

Status: Em construção.
